# Task2-Weather-App
Weather Application using OpenWeatherMap API | CODTECH Internship Task 2

🌦️ Weather Application

CODTECH Internship – Task 2

This is a simple and responsive Weather App built using HTML, CSS, and JavaScript.
It fetches real-time weather data from OpenWeatherMap API and displays temperature, humidity, wind speed, and weather conditions for any city.

🚀 Features
🌍 Search weather by city name
📡 Live weather data using OpenWeatherMap API
🌡️ Shows temperature, humidity, wind speed, condition
💡 Clean & responsive UI
⚡ Fast and lightweight — no backend needed

HTML
CSS
JavaScript
